# 시안 2: 시네마

- `mockup.html`은 대표가 2026-11-11에 고른 시안 2(시네마)를 그대로 옮긴 사본이다. 기획서와 빌드 사양이 `M<줄>`로 가리키는 줄 번호는 이 파일의 줄 번호다.
- 사진은 `/assets/…` 경로로만 가리키고 파일은 저장소에 없다. 무료 요금제로 만든 사진이라 git에 넣지 않는다.
- 시안을 화면 크기별로 찍은 렌더도 그 사진이 들어 있어 git 밖의 `docs/private/design/cinema/`에 둔다.
- CDN에서 받는 글꼴(Wanted Sans)과 아이콘(Phosphor) 링크, `#26262A` 미디어 자리 상자는 시안에만 있다. 사이트는 자체 호스팅한 Pretendard, 인라인 SVG 아이콘, 흰 바탕의 워드마크 포스터 카드를 쓴다.
- 시안의 `command`·`closedby`, `inputmode="numeric"`, `#signup` 앵커, 높이를 고정한 버튼도 시안에만 있다. 사이트는 기획서의 규칙을 따른다.
- 만들 때의 기준은 `docs/PLAN.md` v2.0과 빌드 사양(SPEC, 저장소 밖 작업 문서)이다. 둘이 다르면 코드를 바꾸기 전에 먼저 정한다.
- `mockup.html`은 고치지 않는다. 시안과 다르게 만든 점은 기획서에 적는다.
