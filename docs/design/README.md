# 히어로 디자인 시안

2026-10-28에 첫 화면을 'Coming Soon' 후킹으로 여는 구조로 바꾸면서 만든 시안이다. 시안은 HTML 목업이며 폰트는 CDN에서 불러온다. 실제 구현은 2단계에서 Next.js 컴포넌트로 하고, 값은 `src/styles/tokens.css`의 토큰을 쓴다.

| 파일 | 내용 |
| --- | --- |
| `hero-b.html`, `hero-b-*.png` | **확정안(B안, 청첩장 느낌)**. 2단계 구현의 기준 |
| `hero-a.html`, `hero-a-*.png` | 비교용 A안(전체 주황 글자, 입장권 스티커) |
| `hero-compare.png` | 두 안의 첫 화면 비교 |

## B안 구성

위에서 아래로 날짜 줄, 후킹, H1, 보조 문장, CTA, 영상 섹션 순서다.

- 날짜 줄: 가는 선 두 줄 사이에 반짝임과 '2026.12.25 정식 오픈'(`--ink-900`)을 둔다. 청첩장의 날짜 줄 느낌이다.
- 후킹: 가는 'Coming'(Pretendard 300, `--ink-900`)과 굵은 'Soon'(Pretendard 900, `--brand`)을 `--fs-display`로 쓴다. 데스크톱은 한 줄, 1024px 미만은 두 줄이다.
- 'Soon'의 oo는 흰자와 눈동자가 있는 두 눈이고 아래 영상을 내려다본다. 'Coming'의 i 점은 반짝임이다.
- D-day는 `--brand-deep` 왁스 실링 스티커('오픈까지 / D-58', 흰 글자 4.70:1)이며 'n'의 오른쪽 위 어깨에 붙는다.
- 히어로 높이는 `calc(100svh - var(--peek))`이고 내용은 세로 가운데에 놓인다. 기준 화면(1440×900, 390×844)에서 영상 섹션 윗부분이 첫 화면 아래에 보인다. 낮은 화면에서는 아래 13번을 따른다.

## 2단계에서 반영할 것

심사 두 곳(브랜드·후킹, 접근성·성능·구현)과 직접 검토에서 나온 항목이다.

1. 1024px 미만에서 실링이 'n'을 가린다. 'Soon'이 항상 온전히 읽히도록 실링을 'n' 어깨나 단어 옆으로 옮긴다.
2. 1024~1199px에서 떠 있는 반짝임이 'C'와 겹치고 실링이 여백 밖으로 약 22px 나간다. 반짝임은 후킹 기준으로 배치하고 실링은 여백 안에 둔다.
3. 사운드 버디의 첫 방문 말풍선 '소리 켜 볼까요?'를 더한다(2초 뒤 6초, 세션당 한 번, 소리를 켜면 숨김).
4. 반복 모션을 줄인다. 무한 반복을 횟수 제한 반복으로 바꾸고 히어로가 화면 밖이면 멈춘다. 'Soon'의 상하 흔들림과 재생 버튼의 펄스 링은 뺀다. 무한 반복은 사운드 버디만 남긴다.
5. iOS Safari 15.4 지원을 위해 `cqw`와 `color-mix()` 대신 `clamp()`나 px 값을 쓰고 `@supports` 대체값을 둔다.
6. 소개 정의 문장의 강조 구절('정찰제로 투명하게', '미리 경험하게')이 줄바꿈으로 갈라지지 않게 한다.
7. `<title>`과 메타 설명은 `SITE.title`, `SITE.description`을 쓴다.
8. 후킹 글자 등장은 웹폰트가 준비된 뒤 시작한다(최대 700ms 대기). 대체 폰트에서는 반짝임 점과 눈 위치가 어긋난다. 후킹은 첫 화면에서 가장 큰 글자라 LCP 후보이므로, 등장은 투명도 0에서 시작하지 않고 이동만 쓴다.
9. 목업 전용 `navigator.webdriver` 분기를 넣지 않는다.
10. `--glow-hero`가 'Soon' 아래까지 내려와 대비가 2.85~3.0:1로 떨어지는 곳이 있다. 글로우를 위쪽에 한정해 3:1 이상을 지킨다.
11. 사운드 버디의 'zz'가 화면 오른쪽 밖으로 나간다. 왼쪽 위로 떠오르게 하고 말풍선이 보이는 동안 숨긴다.
12. A안에서 가져올 것:
    - 눈이 키보드 포커스를 받은 CTA와 켜진 사운드 버디를 쳐다본다.
    - 영상 포스터의 '라이드' 미리보기를 쓴다(재생을 누르면 길이 존 순서대로 그려진다).
    - 재생·일시정지 버튼을 프레임 위쪽 모서리에 둬 첫 화면 노출분 안에 보이게 한다.
    - 푸터 아래에 사운드 버디 자리를 비운다.
    - 스크롤 등장의 숨김 상태는 첫 화면 아래에 있는 요소에만 건다.
13. 1366×768, 375×667처럼 낮은 화면에서는 히어로 내용이 길어져 영상 노출이 줄고 35% 자동 재생 기준 아래로 내려간다. 화면 높이를 반영해 후킹 크기와 간격을 줄여 노출을 지킨다.
